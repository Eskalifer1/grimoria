# Editing a message catalog

**Read `docs/agents/coding-standards/i18n.md` before writing copy here.** It holds the key
and namespace rules, the ICU rules, and the dark-fantasy writing checklist. This file is a
reminder, not a substitute.

Four things that are expensive to get wrong:

- **Both theme catalogs, one change.** A key added to `standard.json` is written in
  `dark-fantasy.json` in the same edit — never "flavor it later".
- **Flavor the lexicon, keep the sentence.** Theme vocabulary (bind, inscribe, spell,
  grimoire); same structure, same register, length within ~±20%. No archaic grammar.
- **The consequence stays literal.** Errors and warnings are flavored, but what happened and
  what it costs must survive: "Unbound forever. It cannot be recalled." — not "The spell
  returns to the void."
- **A new term goes in the table.** Invented a mapping? Add it to
  `docs/features/dark-fantasy-theme.md` in the same change.
